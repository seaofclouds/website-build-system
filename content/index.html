A build system you own.

Markdown and HTML in, a static website out. About 1,800 lines of commented TypeScript that you copy into your project and then edit until it's yours.

Use this template Read the docs

Makes you a new repo with a clean history — a copy to own, not a fork to track.

Clone it, then: 
npm install
./site
That builds the site, watches for changes, and serves it at `localhost:3000` with live reload. No compile step and no bundler — the TypeScript runs directly under bun, deno, or node.

I really don't want the build system to be a dependency. It was designed and built around the idea of being part of the website that it's building. It should be a ship of Theseus.

Ivy Reese, who wrote it for automerge.org
Replace a plank at a time until none of the original remains, and it's still your site's build system throughout. Everything below follows from that.

Meant to be edited

No config file, no plugin API, no version number. Settings are variables at the top of one file. You add a macro by adding a case to a switch. The extension mechanism is that you have the code.

Small enough to read

Six packages do the work — markdown-it, markdown-it-footnote, prismjs, chokidar, glob, ws — all at build time. Nothing ships to your visitors.

Content is just files

Put a file in content, it appears on the site at that path. Everything beyond that is opt-in through frontmatter, and an HTML file with none is copied through untouched.

It checks its own work

Every internal link and every anchor is verified against the pages just generated, so renaming a heading someone linked to is caught at build time instead of by a reader two years later.

Batteries, all removable

RSS, sitemaps, llms.txt, redirects, drafts, dark mode, and font subsetting that cuts a typeface down to the characters you actually use. Each one is a file you can delete.

Hosts anywhere

The output is a folder of static files. Node 24, bun, or deno to build it; any static host to serve it. GitHub Pages, Cloudflare, and Netlify are a build command and an output directory.

Pulled out of the [automerge.org](https://automerge.org) website so other sites could start from it. The [changelog](/blog/) records what changed on the way out.
