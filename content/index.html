Content is just files

Add about.md to content and it's at /about/. A folder with an index.html and some photos is /gallery/. Markdown and HTML become pages; every other file is served where it sits.

Markdown, extended by macros

Markdown by default, footnotes and syntax highlighting included. Extend it with macros: {{figure}} for images and video, {{aside}} for a note in the margin — or write your own.

Everything a site needs

RSS, a sitemap, llms.txt, Open Graph tags, redirects, drafts and dark mode. A twelve-column layout with four page shapes, and font subsetting that cuts a typeface down to the characters you actually use.

It checks its own work

Every internal link, anchor and asset is checked against the pages just built, and the whole thing typechecks — a renamed heading turns up in the build output, not in someone's broken bookmark.

No compiler, no server

Runs on Node, with nothing to compile and nothing to bundle. ./site builds, watches, and serves at localhost:3000 with live reload; ./site build writes a folder of static files any host will serve.

Written to be edited

Write a page in markdown. Change how it looks in CSS. Change what it does in TypeScript — the settings are constants in one file, and there's no config file and no plugin API.
